# apr-logo-white.png 이 어디서 왔나

에이피알 공식 CI 배포 파일에서 형태를 그대로 가져왔다. 손으로 다시 그리지 않았다.

| 항목 | 값 |
| --- | --- |
| 원본 | https://www.apr-in.com/download/APR_CI.zip 안의 `CI_APR_RGB.png` |
| 규정 | https://www.apr-in.com/apr_ci.html (컬러 시스템 · 로고 배열) |
| 배열 | 공식 "가로형 1" — 심볼 왼쪽, `APR` 워드마크 오른쪽 |
| 비율 | 워드마크 높이 = 심볼 지름 × 0.609, 간격 = × 0.174, 세로 중심 정렬 |
| 색 | 흰 단색. 빨강 면 위에 얹는 반전 판이다 |

만든 방법. 원본은 흰 바탕에 잉크가 얹힌 그림이라 `픽셀 = a×잉크 + (1-a)×흰색` 을
녹색 채널로 풀어 잉크 농도 `a` 를 얻고, 그 `a` 를 알파로 삼아 흰색으로 칠했다.
잉크 기준색은 영역마다 다르다 — 심볼은 빨강(g=10), 워드마크는 먹(g=58).
형태에는 손대지 않고 색만 반전한 것이다.

원본 경계는 `CI_APR_RGB.png` 안에서 심볼 (309,89)-(569,359), 워드마크 (296,409)-(573,508).

## 왜 이 판인가

공식 가이드 시트의 아래 빨강 띠는 분홍 호를 버린 가는 흰 고리를 쓴다. 그 단순화 판도
만들어 실제 크기로 나란히 놓고 견줬는데, 원본을 반전한 쪽이 겹친 호가 만드는 옅은
테두리까지 남아 "여러 겹의 원이 모여 완벽한 원이 된다" 는 심볼의 뜻을 지켰다.
단순화 판은 내가 그린 원이라, 같은 값이면 원본을 쓰는 쪽을 골랐다.

## 배포하지 않는다

이 파일은 남의 상표다. `apr` 가지는 `main` 에 합치지 않으므로 GitHub Pages 로
공개되지 않는다. PDF 파일로만 낸다.
